# Proyecto de montaje

## Necesario para el proyecto
Para programar con Phyton debes de cumplir los siguientes requisitos

- Tener un ordenador con Phyton instalado
- Saber que programa quieres hacer
- Tener conocimientos básicos de programación

## Equipos necesarios

1. Ordenador
2. Router
